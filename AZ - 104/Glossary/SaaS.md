# SaaS (Software as a Service)

**Definition:** Applications delivered over the internet instead of installed locally. You use the software; the vendor manages everything else (infrastructure, OS, runtime, patching).

**Examples:** Microsoft 365, Salesforce, Workday, ServiceNow, Concur, Dropbox.

**Where this fits:** SaaS apps are what Entra ID provides [[SSO]] and [[Conditional Access]] for — users authenticate through Entra ID once and get access to all connected SaaS apps.
