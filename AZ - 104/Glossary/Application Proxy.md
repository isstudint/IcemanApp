# Application Proxy

**Definition:** An Entra ID feature that lets users access on-premises web applications securely from outside the corporate network — **without a VPN**. The on-prem app stays where it is; Application Proxy acts as a bridge.

**Analogy:** A translator standing at the front door of your building — external visitors don't need to learn the building's internal language or have a special pass (VPN). The translator handles the communication for them.

**When to use:** Legacy on-prem apps that can't be moved to the cloud but still need Entra ID's modern security (Conditional Access, MFA, SSO).
