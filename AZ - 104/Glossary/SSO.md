# SSO (Single Sign-On)

**Definition:** Log in **once** with a single set of credentials and access multiple applications without re-authenticating for each one.

**Analogy:** One wristband at a festival that gets you into every tent — instead of buying a separate ticket at each entrance.

**How Entra ID enables SSO:** Users authenticate once against Microsoft Entra ID, and that session token grants access to all connected apps (Microsoft 365, SaaS apps, custom apps) without additional login prompts.

**Protocols used:** [[SAML]], [[OAuth and OpenID Connect]]
