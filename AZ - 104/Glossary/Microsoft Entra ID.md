Microsoft Entra - ID is Microsoft’s cloud-based Identity and Access Management (IAM) service that authenticates users and authorizes their access to applications and cloud resources.



> [!NOTE] My Own Definition
> It is a cloud-based version of Active Directory whose purpose is to manage and organize **identities and access** to cloud resources within the organization.
