# AD FS (Active Directory Federation Services)

**Definition:** An older on-premises tool that links separate Active Directory domains together for cross-organization authentication. Required a separate server installation and configuration.

**Why it's being replaced:** [[Microsoft Entra ID]] does federation **natively** — no separate server to install, no on-prem infrastructure to maintain. AD FS is legacy.
