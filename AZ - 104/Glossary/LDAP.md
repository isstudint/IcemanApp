# LDAP (Lightweight Directory Access Protocol)

**Definition:** A protocol for reading and searching directory information (user accounts, groups, computer objects) in on-premises Active Directory. Port **389**.

**Cloud equivalent:** REST APIs — Entra ID uses REST/Graph API instead of LDAP for directory lookups.
